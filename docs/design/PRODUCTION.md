# تصميم التخمير والإعدادات

تظل الأقسام الرئيسية أربعة. إعدادات المصنع عبر رمز الترس في الحساب؛ الوصفات داخل المشتريات. خط الإنتاج أصبح رابطًا فعالًا يعرض دفعات التخمير، والتقارير ما زالت موسومة قيد الإعداد.

## الإدخال الأدنى

بدء الدفعة: النوع ← المنتج النهائي ← مصدر الخام عند تعدد الخيارات ← الوزن. يعرض النظام الوصفة المعتمدة والخام والمدد، ويملأ المصدر الوحيد تلقائيًا. لا اسم منتج جديدًا ولا كودًا ولا تاريخًا يدويًا.

تفاصيل الدفعة: اسم المنتج، رقم الدفعة، إصدار الوصفة، توقيت المصنع. ثلاث بطاقات تعرض الأصل والمتبقي ووقت البداية. بطاقة المتبقي بلون أخضر هادئ لتوضيح الفرق بينه وبين الكمية الأصلية.

قبل الجاهزية تعرض الشاشة مؤقتًا وموعدًا صريحًا وزر فحص مع تأكيد واحد. بعد الفحص تستبدلها بخانة كمية وزر إرسال للإنتاج. لكل جزء رقم ضمن الدفعة، وكمية وتاريخ وحالة «بانتظار بدء الفرن». لا زر تشغيل فرن قبل تنفيذ الخدمة.

## الحالات والوصول

تحميل وفراغ وخطأ وتعارض نسخة وطلب مجهول النتيجة وانقطاع شبكة. الخطأ في الجلب يعطل إجراءات التفاصيل حتى تحديثها. عدم وجود وصفة معتمدة يوجه لإعداد الصنف، وعدم وجود خام يوضح ضرورة الاستلام.

الحوار أصلي، وعناوين الحقول عربية، والاختيارات تحمل أسماء وصول صريحة. المؤقت لا يعلن كل ثانية لقارئ الشاشة. على الهاتف تتحول البطاقات إلى عمود والجدول يتمرر داخل حاويته؛ لا تجاوز لعرض الصفحة في اختبار 390px. هذا لا يعادل تدقيق قارئ شاشة كاملًا.
