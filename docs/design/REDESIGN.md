# إعادة تصميم واجهة المصنع — 2026-11-05

اختيار المستخدم: نظام مصنع عملي، خلفية فاتحة، جداول واضحة، وإدخال بخطوات قصيرة.

## قواعد التنفيذ

- أربعة أقسام رئيسية فقط. تنقل ثابت واضح، ومحتوى أبيض على أرضية رمادية باردة، وأزرق للإجراء الرئيسي.
- الألوان: خلفية #f5f7fb، سطح #ffffff، نص #182338، ثانوي #526178، إجراء #215dcc، حدود #d9e1ec. الخط العربي المحلي Noto Sans Arabic؛ 13–14 للبيانات، 16 للمجموعات، 26 لعناوين الصفحات.
- شبكة مسافات 4/8/12/16/24/32، أزرار وحقول بارتفاع 44px على الأقل، تركيز لوحة مفاتيح أزرق ظاهر، وعدم الاعتماد على اللون وحده للحالة.
- المكتب: شريط جانبي 224px، شريط حساب 68px، محتوى بعرض أقصى 1440px. الهاتف: تنقل أفقي، محتوى 16px، حقول بعرض كامل، وجداول تتمرر داخل حاويتها.
- استلام جديد: المصدر ← المواد والأوزان ← المراجعة والحفظ. الرصيد الافتتاحي يبدأ بسبب الرصيد، ولا يطلب موردًا.
- تخمير جديد: المنتج ← المصدر والكمية ← المراجعة والبدء. تعرض المراجعة الكمية التي ستنتقل والرصيد المتوقع بعد النقل والمنتج والوصفة.
- العودة بين الخطوات تحتفظ بالقيم. لا POST قبل تأكيد المراجعة. الحفظ المعلق يمنع إنشاء طلب آخر، ويظل التحقق وإعادة الإرسال متاحين.
- اختيار النوع ثم الصنف بمدخل اختيار واحد ظاهر؛ البحث في الخيارات يظهر عند طلبه. البحث وصفحات الخادم محفوظان؛ لا تنزيل كامل للكتالوج.
- الجداول تعرض بيانات حقيقية فقط. حالات الفراغ تشرح البداية وتربط بالصفحات المطلوبة. لا أرقام أداء مصطنعة أو أزرار لخدمات غير منفذة.
- لا تغيير لقواعد الرصيد أو الأدوار أو API. تجربة المتصفح تختبر الإدخال والرجوع والمراجعة والتكرار والانقطاع.

## بوابة الإنهاء

فحص الهاتف والمكتب بصور فعلية، اختبار عدم تجاوز الصفحة، تنقل لوحة المفاتيح وحوارات الإدخال، التحقق من استعادة الطلب، وفحص الأنواع والبناء. قياس تباين الألوان الأساسية لا يعادل تدقيق WCAG كاملًا أو تجربة قارئ شاشة ميدانية.
