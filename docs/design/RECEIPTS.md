# تصميم استلام المواد وأرصدة الخام

المسارات داخل قسم المشتريات نفسه: `/purchases`، `/purchases/stock`، `/purchases/catalog`، وتفاصيل السند `/purchases/:id`. لا قسم رئيسي جديد.

## الإدخال القليل

الاستلام يبدأ بمادة واحدة: المورد ← النوع ← الصنف ← الوزن. المرجع والملاحظة اختياريان، ويمكن إضافة مواد أخرى حتى 25 مادة. تغيير النوع يمسح الصنف السابق. جميع الاختيارات بحث وصفحات من الخادم، ولا تحمل قوائم ضخمة.

زر الرصيد الافتتاحي يظهر للمالك فقط، ويطلب سبب الجرد. الرقم والوقت والفاعل والمصدر والرصيد تنشأ آليًا. لا يكتب العامل أكوادًا أو قيود مخزون.

## مراجعة النتيجة

السجل يعرض رقم الاستلام والمصدر والوزن والحالة ووقت UTC. التفاصيل تعرض الوزن الأصلي والمتبقي ودفعة المصدر. رابط أرصدة الخام يعرض دفعات ذات رصيد موجب مع رابط السند؛ لا يسمي الخام منتجًا نهائيًا.

العكس يظهر للسند المعتمد ويطلب سببًا داخل حوار. يعطل الزر إذا استخدمت المادة أو لم تتوفر صلاحية الافتتاحي. بعد العكس يبقى الأصل ظاهرًا ويصبح الرصيد صفرًا؛ لا يختفي التاريخ.

## الحالات

تحميل وفراغ وخطأ وإعادة محاولة، وتعطيل الحفظ عند انقطاع الشبكة. الطلب المحفوظ الذي فقد رده يبقى قابلًا للتحقق وإعادة الإرسال دون إنشاء مفتاح جديد. رفض المرجع المكرر يبقي البيانات في النموذج لتصحيحها. نماذج dialog أصلية، labels لكل حقل، رسائل status/alert، جدول يمكن تمريره داخل الحاوية على الهاتف.
