# الإشعارات

جرس أعلى صفحات الإدارة يعرض عدد غير المقروء، وسجلًا مرقمًا (30 إشعارًا في الصفحة) وروابط العمليات وتعليم الفرد أو الجميع كمقروء. سجل القراءة مستقل لكل مستخدم ولا يحذف الإشعار. الصلاحيات الحالية للمالك والمدير، بما يتفق مع صلاحيات الإنتاج القائمة.

المصادر: outbox للاستلام والإلغاء وبدء التخمير واعتماد الجاهزية والسحب وبدء الفرن. مراحل التخمير والفرن الجارية تنتج تنبيه اقتراب الفحص ثم موعده ثم تجاوز المهلة حسب السياسة المحفوظة. لكل حدث أو مرحلة/نوع تنبيه معرّف فريد يمنع التكرار. انتهاء المؤقت لا يكمل المرحلة.

الترحيل 011 ينشئ سجل الإشعارات وحالات قراءتها. لا يغيّر outbox أو حركات المواد. يُقرأ آخر السجل أولًا، ويُستكمل الأقدم عبر المؤشر. تهيئة الحركات السابقة تُعالج 200 حدث في دورة، من الأحدث إلى الأقدم، حتى استكمال السجل.

شغّل `npm run notifications:worker` كعملية مستقلة تحت مدير العمليات مع الموقع. يعمل كل 15 ثانية ويحفظ التنبيهات حتى دون صفحات مفتوحة. صفحة النظام تحدّث الجرس والسجل كل 15 ثانية، وتعيد مزامنة الأحداث كذلك إذا كان العامل متوقفًا. إعادة تشغيل العامل لا تكرر الإشعارات. عند إيقاف المضيف تتوقف المعالجة حتى تشغيله؛ عند العودة تُستدرك الأحداث وموعد الفحص والتأخير للمراحل التي ما زالت جارية. لا يُنشأ تنبيه اقتراب منتهي بأثر رجعي. لا يوجد في هذه الشريحة إرسال واتساب أو بريد أو push خارج النظام.

المسارات: `GET /api/v1/notifications` و`POST /api/v1/notifications/read`. القراءة تحدّث حالات المستخدم الحالي فقط، والتحقق من الأصل والجلسة مطبق على التعديل.

تحديث إكمال الإنتاج: السجل يشمل انتهاء الفرن وبدء/انتهاء التصفية والتعبئة والنقل للمخزون والبيع وإيقاف/استئناف الفرن. تنبيهات وقت الفرن لا تُولد أثناء توقفه. أُعيد تشغيل العامل بعد تحديث الإسقاط.
