# دُهن — نظام مصنع دهن العود

بدأ تنفيذ التطبيق بعد مراجعة Astra. الإصدار الأولي الحالي يشمل الدخول والصلاحيات والأصول والأنواع والأصناف والموردين والوصفات المسودة بإصدارات محفوظة في PostgreSQL، مع تدقيق التعديلات ومنع تكرار الحفظ. أضيف استلام الخام والأرصدة الافتتاحية ودفعات المصدر ودفتر الكميات والعكس الموثق. أضيفت إعدادات المصنع واعتماد الوصفات وبدء التخمير والفحص والسحب الجزئي مع حفظ المتبقي وأجزاء الإنتاج. تشغيل الفرن والتوقف والاستئناف والتقارير لم تنفذ بعد. الخطة الكاملة ما زالت مرجع المراحل التالية.

## التشغيل المحلي

المتطلبات: Node.js 22.12 أو أحدث ضمن النسخ المعلنة في package.json، وDocker لقاعدة تطوير معزولة. لا يحتاج الإعداد إلى docker compose.

```bash
npm ci
npm run db:dev
npm run db:migrate
npm run owner:create
npm run dev
```

افتح [التطبيق المحلي](http://localhost:3108). أمر owner:create يطلب البريد والاسم وكلمة المرور بصورة تفاعلية؛ لا يوجد حساب أو كلمة مرور افتراضية، والتسجيل العام مغلق. لا تُرسل رسالة بريد أثناء إنشاء الحساب.

db:dev ينشئ حاوية خاصة باسم duhn-postgres-dev على 127.0.0.1:55438، ويولد أسرارًا عشوائية في .env.local المستبعد من Git. إعدادات المشاريع الأخرى لا تُستخدم. مستخدم التطبيق محدود الصلاحيات، واتصال الترحيل منفصل. إعادة تشغيل الأمر تعيد استخدام الحاوية الحالية دون استبدال الأسرار.

## التحقق

```bash
npm run db:test
npm run check
npm run api:check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

الاختبارات تستخدم حاوية وقاعدة مستقلتين وملف .env.test.local. بياناتها اصطناعية؛ لا تُشغل الاختبارات على قاعدة المصنع. ملف CI يشغل هذه الفحوص في بيئة جديدة. ملخص التنفيذ وحدوده في [حالة الإصدار الأولي](docs/IMPLEMENTATION.md).

## متابعة التنفيذ مع Gemini

انسخ إلى جيميناي:

> اقرأ GEMINI.md وPLAN.md وdocs/PROGRESS.md وdocs/IMPLEMENTATION.md، ثم تابع الجزء التالي المحدد في سجل التقدم. افحص الشيفرة الحالية قبل إنشائها أو تغييرها، وحدّث السجل بالنتيجة الفعلية. لا تعتبر وجود شاشة أو عقد عامًا اكتمال مجال كامل، ولا تضع بيانات الاختبار في بيئة الإنتاج.

المراجعات السابقة: [Astra](docs/reviews/ASTRA-REVIEW.md)، و[Argon](docs/reviews/ARGON-REVIEW.md). ملاحظتا Astra A01 وA02 صُححتا في المواصفات وتوجد أمثلة اختبارات لهما؛ بقية استكمالات T04 لا تزال مفتوحة حسب سجل التقدم.

توثيق التنفيذ: [عقد المواد](docs/MATERIAL-CONTRACT.md)، [OpenAPI للمسارات الحالية](docs/openapi.json)، [تصميم الكتالوج](docs/design/CATALOG.md). لتجديد وثيقة API بعد تعديل العقود: `npm run api:generate` ثم `npm run api:check`.

استلام المواد من قسم المشتريات، وأرصدة الخام من صفحته الفرعية. فحص مطابقة الدفتر دون تعديل البيانات: `npm run materials:check`. تفاصيل حدود التنفيذ في [دفتر المواد والاستلام](docs/MATERIAL-LEDGER.md) وتصميمه في [واجهة الاستلام](docs/design/RECEIPTS.md).

دليل الشريحة التالية المنفذة: [الإعدادات والتخمير والسحب الجزئي](docs/FERMENTATION.md)، و[تصميم الإنتاج](docs/design/PRODUCTION.md).
